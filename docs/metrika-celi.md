# Цели Яндекс.Метрики: `partner_click` и `tool_view`

Инструкция для владельца (T-006). Код уже готов и выложен: `assets/kd-track.js` отправляет два
события через `ym(113423664, 'reachGoal', ...)`. Не хватает только целей в интерфейсе счётчика —
без них Метрика эти события не считает.

## Почему нет пункта «внешняя цель»

«Внешняя цель» — это про другой продукт (приём событий из внешних систем), на сайте она не нужна.
Для событий из кода в Метрике есть ровно один подходящий тип — **«JavaScript-событие»**. Он и
называется «цель, которую нельзя получить по URL».

## Что отправляет сайт

| Идентификатор | Когда срабатывает | Параметры |
|---|---|---|
| `partner_click` | клик по внешней ссылке, если она партнёрская (`rel="sponsored"`) или ведёт на маркетплейс | `platform` — домен, `from` — страница, с которой ушли |
| `tool_view` | открытие страницы-инструмента: `/calculator/`, `/builder/`, `/tests/`, `/checklist/` | `tool` — какой инструмент открыли |

Идентификатор в интерфейсе должен совпадать с именем в коде посимвольно, включая подчёркивание:
`partner_click`, `tool_view`. Если написать `partnerClick` или `partner-click` — цель останется
пустой, и это будет выглядеть как «сайт не считает», хотя причина в опечатке.

## Как завести (5 минут)

1. Открыть <https://metrika.yandex.ru> под аккаунтом, у которого есть доступ к счётчику
   **113423664** (kabinetdoma.ru).
2. Слева выбрать счётчик → **«Настройка»** → раздел **«Цели»**.
3. **«Добавить цель»**. Тип — **«JavaScript-событие»**.
4. Поля:
   - **Идентификатор цели**: `partner_click` (ровно так, латиницей, без пробелов);
   - **Название**: «Клик по партнёрской ссылке»;
   - **Описание**: не обязательно, можно «уход на маркетплейс со страницы статьи».
5. **«Сохранить»**. Повторить пункты 3–5 для второй цели: идентификатор `tool_view`,
   название «Открытие инструмента».
6. Обе цели должны оказаться в статусе «Активна» — не «Остановлена».

Автоматической цели по клику на внешнюю ссылку в Метрике нет, поэтому руками заводить только эти
две; остальное (визиты, страницы, источники) считается само.

## Как проверить, что работает

1. Открыть любую статью на <https://kabinetdoma.ru>, дождаться полной загрузки (счётчик грузится
   в конце страницы) и кликнуть по карточке товара — откроется маркетплейс в новой вкладке.
2. Через 10–30 минут: **«Отчёты»** → **«Конверсии»** → отчёт **«Достижение цели»**, в фильтре
   выбрать `partner_click`. Если в строке появился хотя бы один визит — цель работает.
3. Альтернатива без ожидания: в списке целей у каждой есть счётчик достижений за последние сутки;
   он тоже обновляется с задержкой, но быстрее отчётов.
4. `tool_view` проверить так же: открыть <https://kabinetdoma.ru/calculator/>.

Если через сутки достижений ноль, а клики были — смотреть по порядку: (1) идентификатор в цели
совпадает посимвольно, (2) цель «Активна», (3) в браузере не включён блокировщик, который режет
`mc.yandex.ru` (в нём счётчик не загружается вообще, и это не ошибка сайта).

## Что от этого получится

- `partner_click` даст конверсию «клик по товару» по каждой статье и источнику — станет видно,
  какие материалы приводят людей в маркетплейс, а какие только читают.
- `tool_view` покажет, пользуются ли калькулятором и конструктором: это единственные страницы,
  где человек что-то делает, а не читает.

Кода это не касается: менять `assets/kd-track.js` и пересобирать сайт не нужно.
