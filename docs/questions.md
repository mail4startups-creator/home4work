# Вопросы между чатами

Один файл на весь проект. Здесь чаты задают вопросы друг другу и отвечают на них — вместо
пересказа через владельца. Каждый чат читает этот файл в начале сессии (`AGENTS.md`, п. 1).

## Как пользоваться

- **Задать вопрос:** дописать новую запись в конец «Журнала» по формату ниже. ID — следующий
  свободный по порядку, не переиспользовать.
- **Ответить:** заполнить `**Ответ:**` (с датой) и поменять `**Статус:** открыт` на `закрыт`.
  Отвечает только адресат; остальным отвечать нельзя, даже если ответ очевиден.
- **Закрытые вопросы не удаляются** — это журнал решений.
- **Больше двух реплик** — это уже решение, а не вопрос: перенеси суть в `docs/concept.md`,
  `docs/architecture.md` или `docs/tasks.md`, а вопрос закрой ссылкой.
- **Не блокируйся:** если ответ нужен, но работа идёт — сделай незаблокированную часть и укажи
  в ответе владельцу «ждёт Q-00X».
- Адресаты: `разработка`, `контент`, `продвижение`.

## Формат записи

````
### Q-001 · контент → разработка · 2026-11-03
**Статус:** открыт
**Вопрос:** одно-два предложения, в чём именно вопрос.
**Контекст:** необязательно: файлы, цифры, ссылки на документы.
**Ответ:** —
````

Проверка и просмотр:

```
node tools/questions.js                 # открытые вопросы
node tools/questions.js --chat контент  # только те, что адресованы этому чату
node tools/questions.js --all           # с закрытыми
node tools/questions.js --json          # машинный формат
node tools/questions.js --check         # проверка формата, exit 1 при ошибке
```
