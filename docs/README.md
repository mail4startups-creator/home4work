# База знаний проекта kabinetdoma.ru

Один вход для всех чатов. Здесь карта: что где лежит и что читать перед работой.
Правила поведения агентов — в `AGENTS.md` в корне.

## С чего начать

| Файл | Зачем |
|---|---|
| `AGENTS.md` | правила для всех чатов, жёсткие ограничения, куда что писать |
| `docs/questions.md` | **общий файл вопросов между чатами** — читать в начале каждой сессии |
| `docs/roles/razrabotka.md` | чат разработки: код, сборка, деплой |
| `docs/roles/kontent.md` | чат контента: статьи, каталог, хаб |
| `docs/roles/prodvizhenie.md` | чат продвижения: каналы, семантика, метрики |
| `docs/concept.md` | что за продукт, для кого, на чём зарабатываем, что нельзя |
| `docs/architecture.md` | как устроен сайт и сборка, источники правды, грабли |
| `docs/tasks.md` | актуальное состояние (числа с датой), планы по ролям, блокеры |

## Устарело в `README.md` (проверять по `docs/architecture.md`)

- «15 экспертных статей» и «4 модуля тестов» — числа менялись, актуальные в `docs/tasks.md`.
- Раздел про `contentData.ts`, `src/data/` и загрузку файла через GitHub UI — это описание
  старого проекта. Сейчас тексты в `data/articles/*.json`, сборка локальная.
- «Цены показываются как ориентир» — верно только для `price_mode: "note"` и для конструктора;
  в статьях блок товаров печатается без цен.
- Почта, партнёрские заявки, Яндекс 360 — рекомендации, не состояние проекта.

## Правила ведения базы знаний

1. Новое знание — сразу в файл, а не в переписку. Если знание одноразовое (разбор инцидента) —
   `docs/archive/` с датой в имени.
2. Любое число — с датой. Числа дублировать нельзя: актуальные счётчики только в `docs/tasks.md`.
3. Правило, которое нарушили и получили поломку, — в `docs/architecture.md` («Грабли») или в
   `docs/roles/*.md`, чтобы следующий чат не наступил снова.
4. Решённый вопрос из `docs/questions.md` превращается в строку в `docs/tasks.md` или в правило
   в `docs/concept.md`/`docs/architecture.md`; сам вопрос закрывается, но не удаляется.
5. Файлы не переименовывать без причины: на `HANDOFF.md` и `docs/questions.md` ссылаются
   инструкции других чатов.
