# Кабинет Дома (KabinetDoma.ru)
> Экспертный цифровой портал об эргономике домашнего офиса, мебели, тишине и продуктивной удаленной работе. Монетизация через партнерские программы маркетплейсов (CPA) в РФ.

---

## 📌 О проекте

«Кабинет Дома» — нишевое доказательное медиа, ориентированное на удаленных специалистов, родителей с детьми в типовых квартирах, IT-инженеров и фрилансеров в России.

### Ключевые возможности:
1. **База знаний (15 экспертных статей):** подробные прикладные руководства по зонированию однушек, выбору комнат (спальня vs кухня vs балкон), расположению стола относительно окна и батареи, подбору подъемных столов, эргономичных кресел с сеткой и скринбаров.
2. **Интерактивные тесты и диагностика (4 модуля):**
   - *Аудит мебели и тела:* экспресс-тест осанки, монитора и освещения с баллами риска, бесплатными лайфхаками и подбором оборудования.
   - *Психотип удаленщика:* тест готовности к 100% удаленке vs гибрид vs офис с разбором архетипов (Deep Work Master, Офисный экстраверт, Социальный гибрид).
   - *Индекс сенсорного выгорания:* определение уровня перегруза нервной системы от шума, отсутствия прогулок и экранного времени.
   - *Калькулятор выгоды удаленки:* расчет сэкономленных часов чистой жизни (полных суток без пробок в год) и сохраненных денег на дороге и ланчах.
3. **Интерактивный калькулятор эргономики:** расчет высоты столешницы и сиденья под индивидуальный рост по антропометрическим нормативам **ГОСТ 13025.3-85** и **ГОСТ 21889-76**.
4. **Конструктор рабочего комплекта:** сборка персонализированного сетапа под заданный бюджет с автоматическим подсчетом стоимости.
5. **Чек-лист тишины с детьми:** интерактивный трекер правил фокуса (метод «Светофор», звукоизоляция, ENC-микрофоны).
6. **Каталог проверенной эргономики:** проверенные товары со спецификациями и плюсами/минусами. Цены показываются как ориентир («Ориентир — N ₽», число из `price_rub`), по ним же считается стоимость сетапа; у товара с `price_mode: "hidden"` цены нет. Данные ведутся в `data/catalog.js`.
7. **Автономность и мобильная скорость:** все иллюстрации хранятся локально — SVG-схемы и фотоподборка в `/images/`, внешних CDN с картинками нет; у всех `<img>` прописаны `width`/`height` и `loading="lazy"`, шрифты подключаются с `display=swap`.
8. **Юридическая чистота:**
   - Полное соблюдение **152-ФЗ РФ** (нулевой сбор персональных данных, отсутствие навязчивых форм).
   - Маркировка партнерских интеграций по **347-ФЗ РФ** (токены ERID).

## 🛠 Технологический стек

- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons.
- **Бэкенд & ИИ:** Express.js (`server.ts`), Google GenAI SDK (`@google/genai`), модель **Gemini 3.8 Flash**.
- **Деплой:** GitHub Pages (статический SPA через `404.html` + CNAME) или любой веб-хостинг в РФ (Beget, TimeWeb, HotHat).
- **Каталог:** `data/catalog.js` (`window.KD_CATALOG`: товары, офферы, сетапы, привязки статей), рендер `assets/kd-catalog-render.js`, панель `assets/kd-admin-catalog.js`, проверка перед выкладкой — `node tools/verify-build.js`.

## 🏗 Сборка и выкладка

Одна команда из корня: `node tools/build.js` (флаги `--only=<slug>` — одна статья, `--skip-prerender` — только постобработка). Порядок шагов важен:

0. `apply-articles.js` — собирает массив статей в `assets/index.js` из `data/articles/*.json`.
1. `prerender.js` — Chrome снимает готовый DOM каждой страницы в `_prerender/` (локальный сервер поднимается автоматически).
2. страницы переносятся в корень сайта;
3. `seo-fix.js` — выверенные title/description из `tools/seo-pages-*.json`, JSON-LD (`Article`/`WebPage`/`FAQPage`/`BreadcrumbList` с `@id`, равным адресу страницы) и блок перелинковки;
4. `optimize-html-images.js` — все фото локальные (`/images/...`), с `width`/`height`, `loading="lazy"` и `fetchpriority="high"` у первой картинки;
5. `make-redirects.js` — 17 meta-refresh страниц и `_redirects` с 301 для Cloudflare;
6. `inject-tracker.js` — подключает `assets/kd-track.js` ко всем каноническим страницам (кроме редиректов);
7. `sitemap.js` — адреса ровно как в canonical, `lastmod` меняется только при правке страницы;
8. `verify-build.js` — проверка правил, в конце должно быть «всё чисто».

Постобработка обязательна: без неё повторный пререндер затирает разметку и обрезает описания.

Гидрация не включается: приложение монтируется через `createRoot` и при первом рендере подменяет пререндеренный DOM, поэтому `hydrateRoot` даёт расхождение разметки (React сообщает об ошибке и всё равно перерисовывает дерево). Выигрыш дают сам пререндер, локальные картинки и приоритет первой из них.

### Цели в Метрике

`assets/kd-track.js` сам отправляет два JavaScript-события в счётчик 113423664:

- `partner_click` — клик по ссылке с `rel="sponsored"` или ведущей на маркетплейс; параметры `platform` (домен) и `from` (страница, где кликнули);
- `tool_view` — открытие `/calculator/`, `/builder/`, `/tests/`, `/checklist/`; параметр `tool`.

Чтобы события начали считаться, в Метрике (Настройки → Цели → JavaScript-событие) надо один раз завести цели с этими именами. Остальные цели — калькулятор, конструктор, тесты, чек-лист, клики по маркетплейсу — можно добавить URL-целями без правки кода.

### Где править тексты статей

Тексты живут в `data/articles/<slug>.json` — по файлу на статью, обычным JSON с полями `title`, `subtitle`, `sections`, `faqList`, `seo` и т. д. Порядок вывода и состав статей задаёт `data/articles/order.json` (массив slug).

Бандл — не источник правды: `tools/apply-articles.js` сам собирает массив из JSON и вставляет его в `assets/index.js` между маркерами `/*kd:articles:start*/` и `/*kd:articles:end*/`. Сборка вызывает этот шаг первой, а `verify-build.js` падает, если бандл разошёлся с JSON. Поэтому править текст прямо в бандле бессмысленно — следующая сборка его перезапишет.

Цикл правки текста: изменить JSON → `PORT=8099 node tools/build.js` → `verify-build.js` скажет «всё чисто» → коммит, пуш и `tools/deploy-prod.sh --push`. Проверить только соответствие бандла и JSON без сборки: `node tools/apply-articles.js --check`. Файл HTML в `article/<slug>/index.html` — артефакт пререндера, руками его не трогают.

Поля `author: "editorial"` в JSON при сборке превращается в авторский объект редакции из бандла. Новая статья: файл `<slug>.json`, строка в `order.json`, запись в `tools/seo-pages-*.json` и карточка в хаб `articles/index.html`.

### Ручные правки внутри `assets/index.js`

Бандл собирается вне репозитория, поэтому часть данных правится в нём текстовыми заменами (кроме массива статей — его собирает `apply-articles.js`). При пересборке из исходников эти вставки надо перенести в source, иначе они пропадут:

- `window.KDPrices = { price(id), sum(ids) }` в начале файла — цены читаются из `price_rub` в `data/catalog.js`;
- литералы `priceRub:(window.KDPrices.price("<id>")||<число>)` у всех товаров каталога (сейчас 29) — это те же «ориентиры», что печатаются в карточках;
- бюджет пресета — `(window.KDPrices.sum(t.includedProductIds)||t.budgetRub)`;
- все `imageUrl` и аватар редакции ссылаются на локальные файлы (`/images/...`, `/logo.png`) — без внешних CDN.

После ручной правки: `node --check assets/index.js` и `node tools/verify-build.js`; он же падает, если у товара из сетапа нет `price_rub`.

## 📖 Пошаговая инструкция по управлению контентом

### Как добавить новую статью за 2 минуты:
1. Откройте панель управления (`/#admin`, PIN: `2026`).
2. Во вкладке **«AI-Генератор»** выберите быструю тему или введите свою (например, *«Как выбрать подставку для ног под стол»*).
3. Нажмите **«Сгенерировать статью через Gemini API»**.
4. Нейросеть сгенерирует структурированный материал. Нажмите **«Открыть в редакторе»**.
5. Проверьте текст, при необходимости скорректируйте ссылки на товары.
6. Нажмите **«Сохранить статью»** — статья мгновенно появится на сайте в браузере.
7. Перейдите во вкладку **«Экспорт»** и нажмите **«Скачать файл contentData.ts»**.
8. Зайдите в ваш репозиторий на GitHub, откройте папку `src/data/`, нажмите *Upload files* и загрузите скачанный файл `contentData.ts`.
9. Через 1 минуту GitHub Pages автоматически обновит сайт в продакшене.

### Как добавить товар и привязать его к статье или сетапу:
1. Откройте админку (`Ctrl + Shift + A`, PIN `2026`) и нажмите кнопку **«Каталог»** внизу справа (или `Ctrl + Shift + K`).
2. Вкладка **«Товары»** → «Добавить товар»: id (латиница с дефисами), название, бренд, описание. Фото добавляется кнопкой **«Загрузить фото…»**: файл сжимается в браузере до 640 px и уезжает внутрь `catalog.js`, поэтому отдельная папка с картинками не нужна. Можно и вставить ссылку (`https://` или `/images/...`).
3. Вкладка **«Офферы»**: выберите товар и добавьте площадку. Пустая ссылка = кнопки нет; `kind: "search"` даёт «Найти на Ozon», `kind: "card"` — «Купить» и требует прямую ссылку без `/search`. Для партнёрской ссылки заполните `erid` и рекламодателя — на сайте появится пометка «Реклама» и `rel="sponsored"`. Пометка ставится только офферам `card` с `erid`: `search` — обычная навигация, рекламой не является, и `verify-build.js` падает, если у такого оффера появится `erid`.
4. Вкладка **«Сетапы»**: уровень 1–3 (названия уровней правятся в блоке «Уровни сетапов»), состав — галочками.
5. Вкладка **«Привязки статей»**: slug статьи из адреса `/article/<slug>/` и товары. Блок с карточками появится в конце статьи.
6. Нажмите **«Скачать catalog.js»**, замените файл `data/catalog.js`, выполните `node tools/verify-build.js` и выложите сборку.

## 🤖 Инструкция по управлению контентом и AI-генератору статей

В сайт встроен полноценный инструмент для генерации и редактирования экспертных материалов:

### 1. Как открыть скрытую админку:
- Прокрутите в самый низ страницы (футер) и нажмите на незаметную иконку замка 🔒 справа внизу (или используйте PIN: `2026`).

### 2. Подключение API-ключа Google Gemini:
Для работы настоящей большой языковой модели **Gemini 3.8 Flash** в реальном времени требуется бесплатный API-ключ:
1. Перейдите в [Google AI Studio (aistudio.google.com/apikey)](https://aistudio.google.com/apikey) и войдите под вашим Google-аккаунтом.
2. Нажмите **«Create API key»** (занимает 30 секунд, бесплатно).
3. В админке сайта во вкладке **«AI-Генератор статей»** вставьте полученный ключ в поле *«API-ключ Google Gemini»* и нажмите **«Проверить и сохранить»**. Ключ сохранится в вашем браузере.
4. *Альтернатива для хостинга:* пропишите переменную в файле `.env` на сервере: `GEMINI_API_KEY=ваш_ключ`.

### 3. Как генерировать глубокие статьи:
1. Введите **Тему статьи** (например: *«Как подготовиться к удаленной работе во время поездки»*).
2. Выберите **Категорию** (для поездок и нестандартных тем выберите раздел **«Прочее»**).
3. В поле **«Подробный план, контекст и ТЗ автора»** укажите тезисы, о чем именно нужно написать:
   - 1. Что взять из техники (GaN-зарядка, пауэрбанк с PD, подставка под ноут).
   - 2. О чем договориться с шефом (асинхрон, 2-часовые окна связи, статус).
   - 3. Кибербезопасность ноутбука (BitLocker/FileVault, 2FA без SMS в роуминге).
   - 4. Связь и риски (eSIM, точка доступа, коворкинги поблизости).
   - 5. Психологическая граница и защита отпуска (закрыть ноут в 11:00, сейф, без созвонов на пляже).
4. Нажмите **«Сгенерировать глубокую статью через Gemini API»**. Нейросеть развернет каждый ваш пункт в детальный практический раздел со списками, предупреждениями и конкретными девайсами.
5. Статья автоматически сохраняется в список статей сайта.
6. Во вкладке **«Редактор и проверка ссылок»** вы можете внести любые правки в текст и настроить партнерские ссылки на Ozon / Маркет / WB.
7. Во вкладке **«Экспорт файла contentData.ts»** скачайте готовый файл и замените им `src/data/contentData.ts` в репозитории для фиксации на GitHub Pages.

## 📈 Сценарии продвижения сайта (Минимум рутины, максимум SEO)

Так как цель проекта — **пассивный доход с минимумом личного времени**, используйте стратегию вечнозеленого органического трафика:

1. **Поисковая оптимизация (SEO Яндекс и Google):**
   - Индексация низко- и среднечастотных запросов: *«калькулятор высоты стола под рост»*, *«куда поставить рабочий стол у окна»*, *«метод светофор удаленка с детьми»*, *«лучшее сетчатое кресло для поясницы»*.
   - Интерактивные калькуляторы обеспечивают **высокое время на сайте (Time on Site > 3 минут)** и низкий показатель отказов, что резко поднимает позиции сайта в Яндексе.
